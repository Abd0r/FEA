[SCENARIO 4] what distinguishes FEA from PIM, CIM, RC, and what does not
class stores              computes                      distinction
  PIM separate array      logic near or in array        FEA has no separate logic block
  CIM separate array      analogue op inside array      FEA computes during capture itself
  RC  separate array      crossbar physics              FEA DBW transport, not RC resistance
  FEA state IS the result capture event IS write+compute+storesame physical entity

  the conceptual distinction is real: in FEA compute and memory are one
  physical entity, so there is no load, store, or data bus.
  what that distinction does NOT establish, and Reviewer 3 point 2 requires:
    - that FEA is faster than RC hardware
    - that FEA is more energy-efficient per confirmed operation
    - that either architecture is preferable for a given workload
  those need the matched-boundary numbers in SCENARIO 1 against sourced
  references. Until then the honest claim is architectural, not performance.
  label: conceptual comparison only. No superiority is asserted.
