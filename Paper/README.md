# Paper

`FEA-architecture.pdf` is the **April 2026 architecture paper (v1, 22 pages)**. It is
retained for provenance: it is the long-form description the simulation suite was
built against, and it is **not** the current manuscript.

The current revision of the manuscript is the v3 submission under review at
*Scientific Reports* ("Free Electron Absorption: A Transistor-Free Computing
Architecture with Unified Memory-Compute on Hydrogen-Passivated Silicon"). Its
numbers come from the suite in `simulations/v3/`; the v1 paper's headline numbers
(14.1 TB, 3.8 W, 9.19 GHz, 1.1 TB/s, the production-SoC comparison) were corrected
or withdrawn in that revision. Read the v1 PDF for the architecture, not for the
current numbers.
